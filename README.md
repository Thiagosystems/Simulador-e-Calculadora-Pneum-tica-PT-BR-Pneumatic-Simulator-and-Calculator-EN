# Simulador-e-Calculadora-Pneum-tica-PT-BR-Pneumatic-Simulator-and-Calculator-EN
Simulador + Calculadora Pneumática Bancada virtual para montar circuitos pneumáticos (válvulas, cilindros, mangueiras) e ver o ar circular em tempo real, junto com uma calculadora que dimensiona cilindros: força de avanço/recuo, consumo de ar, vazão necessária e verificação de flambagem da haste.
